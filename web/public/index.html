Settings

Admin Mode

Shows the behind-the-counter tools: Config Files, Artwork, Live Logs, the Dry run checkbox and every delete and remove button. Disable it for a cleaner shelf when you only build lists and sync them. Nothing is changed or deleted by enabling or disabling it; it's remembered in this browser only.

Screen Effects

The worn-tape look: the tracking band that rolls down the screen now and then, tape grain, scanlines, the dark edges of the tube and the blinking PLAY. Disable it for a calmer, cleaner screen; the colors, signage and layout stay the same. It's saved on the server, so it holds for every browser and through restarts.

Media Servers

Every collection, playlist and genre goes to every server here, unless its own Servers setting picks some. Each server has its own admin user and playlist viewers.

Web Access

No password is set, so the UI only opens from your local network.

Two-Factor Sign-In

Sign in with your password and a code from an authenticator app (Google Authenticator, Microsoft Authenticator, 1Password, Bitwarden, Aegis, 2FAS and the like).

Scan this with your authenticator app, or type the key into it. Then enter the 6-digit code it shows.

Your recovery codes. Each one signs you in once without the app. Keep them somewhere safe, like a password manager: they won't be shown again.

    Backup

    Your whole config folder as one zip: settings and keys, collections, playlists, genres, list files and artwork. It holds your API keys and passwords, so keep it somewhere private. Restoring puts its files back and leaves any others alone; the config as it was is saved in backups/restores first.

    Download Config

    Bulk Operations

    Delete every configured collection or playlist from the media server, or take StaffPicked's artwork off every configured genre. You see the full list and approve it first. Config files stay, and the next sync puts back any that are in season.

    Import from Emby
    
      
    
      
    
    
    
    What's already on Emby (collections, playlists, and genres that have artwork), and whether StaffPicked manages it. Importing adds it to StaffPicked, artwork included. A collection whose MDBList or Trakt list can be found keeps following that list; for one it can't find, you're asked for the list's link, or Skip to keep a fixed list of the films it holds now. Playlists become fixed lists. Linking renames a StaffPicked entry whose name is nearly the same, so it updates the one already there instead of building a second. Only the config folder changes here; nothing on the server is changed or deleted.
